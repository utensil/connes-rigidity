# Connes-Zhou comparator challenge

This challenge is the independent statement boundary for the formalization of
[arXiv:2608.02327](https://arxiv.org/abs/2608.02327), complete relative to the
cited EJZK input.
`F_ConnesZhou.lean` repeats the public vocabulary needed to read Theorem A
and contains the theorem with an intentional proof hole. The solution module
is `Connes`.

The challenge must stay independent of the solution. Keep the permitted axiom
list minimal and run the final check with nanoda on Linux inside landrun.
See [../docs/COMPARATOR.md](../docs/COMPARATOR.md).
